| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

The SRM Artificial Intelligence Lab takes the security of our applications and community seriously.

If you discover a security vulnerability within this project, please follow responsible disclosure:

1. **Do not** file a public GitHub issue.
2. Email full vulnerability details, reproduction steps, and potential impact to **sail@srmist.edu.in**.
3. We will acknowledge receipt within 48 hours and provide a timeline for remediation.
4. Once the issue is resolved and deployed, appropriate credit will be acknowledged in release notes.
